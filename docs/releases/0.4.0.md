## DeepSeek++ 0.4.0

0.4.0 builds on the 0.3.0 Chrome / Edge / Firefox multi-browser baseline, adding local Shell / Office document tools, Agent-style continuous execution, automation task triggers, and output speed display, and fixing a batch of long-task stability issues.

### Key Changes

- Bundles the official OfficeCLI Skill and a PPT style library covering DOCX, XLSX, PPTX, Pitch Deck, Academic Paper, Financial Model, Dashboard, and Morph PPT document scenarios.
- Adds the Shell MCP Native Messaging host and installer script, which can create a Shell preset and call local command tools through `shell_exec` / `shell_status`.
- The Shell installer first checks for the command-line OfficeCLI and places the user's local tool directory ahead of project dependency directories, avoiding accidental use of the hosted generation path.
- Adds Agent-style continuous execution: MCP tool results can be sent back into the same conversation to continue generating, letting DeepSeek decide the next step from execution results like Claude Code / Codex.
- Continuous execution is displayed collapsed by Step, and supports stopping mid-run and restoring after refresh.
- Tool execution progress and results can be restored after a page refresh, reducing lost state in long tasks.
- Adds a live `tok/s` speed display while a reply is being generated.
- Automation tasks keep their "Automation" positioning: they handle run-now and cron/RRULE scheduled triggers; triggered tasks can reuse presets, memory, MCP tools, and the Agent-style continuation chain.
- Fixes issues with stream cancellation, timer cleanup, tool parse counting, multi-segment offsets, tool record restoration, and mock catalog differences.
- The README adds a 0.4.0 change recap, OfficeCLI/Shell MCP notes, and diagrams of tool continuation and speed display, and restores the Automation task naming.
