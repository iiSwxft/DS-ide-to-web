## DeepSeek++ 0.7.4

0.7.4 is a project sidebar and language experience enhancement release, letting project conversations be managed directly in the DeepSeek history sidebar and making English/Chinese interface selection clearer and more stable.

### Key Changes

- **Project sidebar enters the DeepSeek history area**: projects appear in the native DeepSeek history sidebar, can be expanded to view related conversations, and let you open conversations inside a project directly.
- **Smoother project conversation organizing**: add the current conversation to a project, remove it from a project, or specify a project context for the next new conversation, reducing back-and-forth when organizing tasks.
- **Native conversation menu supports project actions**: in the DeepSeek history conversation menu you can quickly add a conversation to or remove it from a project, so organizing projects no longer relies only on the side-panel page.
- **Clearer interface language control**: Settings adds an interface language section where you can choose Follow browser, Simplified Chinese, or English, and see the currently active language.
- **More stable project entry points**: project sidebar rendering, menu clicks, history title extraction, and repeated refresh handling are steadier, lowering the chance of project entries flickering, being hidden by mistake, or titles mixing in time text.
- **Regression coverage strengthened**: adds tests for project sidebar management, native menu project actions, language copy, and history title extraction; pre-release checks continue to cover multi-browser builds and asset verification.
