## DeepSeek++ 1.0.1

1.0.1 is an experience and reliability patch after 1.0.0, making conversation speed, project conversations, and tool execution boundaries clearer and more controllable.

### Key Changes

- **Usage and speed visibility**: Settings adds a usage statistics entry where you can view local statistics such as tokens, requests, duration, and speed, helping users understand the execution pace of the current conversation and tool chain.
- **Clearer tool execution boundaries**: MCP tool execution and multimodal capability checks are stricter, reducing accidental triggers of tools that are not enabled, not configured, or unsuitable for the current environment.
- **Steadier project conversation experience**: conversation links and theme styles in the project sidebar continue to be polished, with clearer lists, links, and status in dark/light themes.
- **Store assets completed**: adds the icons and promotional images used by the Chrome Web Store so the store page can show the current product UI more accurately.
- **Regression coverage continues to grow**: adds tests for token speed, usage statistics, MCP execution policy, multimodal policy, side-panel navigation, and project sidebar organization.

### Chrome Web Store Update Notes

- Adds a Usage settings entry for local token, request, duration, and speed statistics, making the current conversation pace easier to understand.
- Tightens MCP tool execution and multimodal capability checks, reducing accidental runs when a tool is disabled, unconfigured, or unsuitable for the current environment.
- Polishes project-sidebar conversation links and theme styling so lists, links, and state cues are clearer in light and dark modes.
- Adds Chrome Web Store icon and promotional images so the listing better reflects the current product surface.
- Expands regression coverage for token speed, usage statistics, MCP, multimodal behavior, and project-sidebar organization.
