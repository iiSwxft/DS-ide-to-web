## DeepSeek++ 0.6.3

0.6.3 is a conversation export entry consolidation release, moving the export action back into the DeepSeek reply toolbar so archiving the current conversation fits everyday reading and organizing workflows.

### Key Changes

- Choose an export format in the same row as the official action buttons below a DeepSeek reply, with no need to switch to a separate side-panel page.
- The current conversation can be exported as an HTML, Markdown, or PDF file, suited for reading, archiving, and organizing before sharing.
- File names, attachment references, message metadata, and the readable mode continue to converge, making exported content easier to search and keep long term.
- Store copy and privacy notes are aligned to local downloads, clarifying that exported files are saved locally through the browser.
- Conversation export tests cover the reply toolbar entry, format selection, naming, and the PDF export path.
