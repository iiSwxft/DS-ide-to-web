## DeepSeek++ 0.7.3

0.7.3 is a project context and permission tightening stability release, making DeepSeek++ steadier in project tasks, Browser Control, memory injection, automation, and long-task continuation while reducing unnecessary permission burden.

### Key Changes

- **More stable project context**: project instructions, project memory, and context from linked DeepSeek conversations are used more consistently, so handling project tasks needs less repeated pasting of background.
- **More restrained Browser Control permissions**: Browser Control no longer depends on the extra tab group permission; the feature remains off by default, and page text snapshots and visible browser actions are provided only after the user enables it and selects a target tab.
- **Tighter memory and prompt pipeline**: memory filtering, project memory, and prompt preparation are more accurate, reducing missing or duplicated context and context entering the wrong task scope.
- **Steadier automation and long-task continuation**: automation task state, tool result return, and multi-step continuation continue to be polished, better suited for scheduled tracking and tasks that need sustained progress.
- **Cleaner streaming output**: tool calls and context injection in long replies are handled more reliably, lowering the chance of technical markers lingering in the body or interrupting normal output.
- **Regression coverage continues to grow**: adds and strengthens tests for project context, project memory scope, Browser Control permissions, sync data, automation state, and streaming tool text; pre-release checks continue to cover multi-browser builds and asset verification.
