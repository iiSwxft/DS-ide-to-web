## DeepSeek++ 1.0.5

1.0.5 is a project context and Agent continuation stability update, making new conversations in a project start more directly and project conversation titles more accurate, while reducing repeated inline agent continuation, exposure of internal continuation messages, Vision upload misjudgments, and code block download buttons covering content.

### Key Changes

- **Project conversation organization**: the project sidebar adds a "Start new conversation in project" entry, and the new conversation directly inherits the selected project context.
- **Project title refresh**: project conversations prefer real history titles, and default DeepSeek titles or untitled placeholders no longer overwrite valid titles already saved.
- **Agent continuation stability**: the inline agent reduces repeated continuation when a complete answer has already been given and hides internal continuation messages, keeping the final answer and history cleaner.
- **Vision and code block experience**: Vision image upload is more compatible with the successful-but-pending-review status returned by DeepSeek; the code block download button now uses floating positioning, reducing its effect on code content layout.
- **Open-source license**: the project license and package metadata are aligned to Apache-2.0, keeping README badges and source package information consistent.
- **Regression coverage**: adds regression tests for project conversation titles, the project sidebar, inline agent continuation, history cleanup, Vision upload, and code block downloads.

### Chrome Web Store Update Notes

- The project sidebar adds a one-step action to start a new conversation inside a project, and project conversation titles refresh from history without being overwritten by default titles.
- Inline agent continuation is more reliable: it avoids replaying steps after a complete answer and hides internal continuation messages.
- Vision image uploads handle successful but pending/unknown review states more accurately, and code-block download buttons no longer change code-block content layout.
- Regression coverage now includes project context, inline agent continuation, Vision uploads, code-block downloads, and release assets. The project license is aligned on Apache-2.0.
