## DeepSeek++ 1.0.8

1.0.8 fixes three issues users raised strongly: local Skill import, long-content write quota, and Agent concurrency, focusing on making long-running tasks steadier and error messages more actionable.

### Key Changes

- **Local Skill import supports Chinese names and BOM**: importing a `SKILL.md` with a UTF-8 BOM no longer loses the frontmatter, and Chinese names/directories can also be imported (a stable slug is generated automatically as a fallback and can be renamed later in the Skills UI); Windows backslash paths are parsed correctly.
- **Tool record storage quota management**: tool call history now uses budgeted writes, automatically trimming the oldest records before storage fills up, no longer flooding "QUOTA_BYTES" warnings on every tool call; per-record detail/output snapshots are tightened, and the history cap drops from 200 to 100.
- **Local write size aligned to the real limit**: local messages and the `local_file_write` limit are aligned to Chrome native messaging's real ceiling of about 1 MB; oversized writes are intercepted early on both the extension side and the local host side with a clear hint to "write in chunks: write the first half first, then use `append=true` for the rest"; diagnostic logs are recorded when a local host response approaches the limit.
- **Agent concurrency protection**: while an Agent is running, new messages the user sends in the chat box no longer trigger a second duplicate Agent; the old Agent panel is removed in sync when switching, avoiding two panels appearing at the same time; adds an "Agent is running" status hint.
- **Regression coverage**: adds tests for BOM import, Chinese slug fallback, history budget trimming, the local 900 KB boundary, and the Agent concurrency guard.

### Verification

- `npm run compile`
- `npm test`
- `npm run build:chrome`
- `npm run build:all`

### Chrome Web Store Update Notes

- Fixes local Skill imports dropping the `name:` field when `SKILL.md` starts with a UTF-8 BOM (e.g. saved by Windows Notepad), which previously raised "missing a valid name"; Skills with Chinese titles or directories now import with an auto-generated, renameable slug.
- Tool call history no longer logs a quota warning on every call when storage fills up — it proactively trims the oldest records; content writes that exceed the native messaging cap now prompt for chunked writes instead of failing silently.
- Long-running Agents no longer spawn a duplicate Agent task when the user sends a follow-up message, preventing two parallel Agent panels from appearing in the same conversation.
