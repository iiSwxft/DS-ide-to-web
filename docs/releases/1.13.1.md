## DeepSeek++ 1.13.1

1.13.1 is an inline agent experience polish and conversation export stabilization release: inline agent output rendering matches native Markdown, tool status display is more truthful, and the HTML format and download path of conversation export are more reliable.

### Key Changes

- **Inline agent rendering fixes**: Agent output now uses compact block-level layout consistent with native Markdown rendering; extra blank lines left after stripping tool calls are collapsed automatically, and heading levels align with body text.
- **Inline agent UI/UX polish**: tool execution status is shown truthfully (success/failure/in progress), streaming output scrolls more safely, and a neutral footer is shown when paused; icons are now SVG with a unified type and corner-radius system, interaction feedback is more immediate, keyboard and screen-reader accessibility is better; startup failures are no longer silent.
- **Conversation export stabilization**: HTML export includes input/output statistics, and the export and download path is more stable with more reliable download management.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
