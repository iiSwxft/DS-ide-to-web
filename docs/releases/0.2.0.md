## DeepSeek++ 0.2.0

0.2.0 upgrades DeepSeek++ from a "memory + Skill" extension into a full in-browser tool platform, with the MCP tool system and Codex-style automation tasks as the main additions.

### Key Changes

- Adds MCP server management, tool discovery, health checks, call history, timeouts, and result size limits.
- Supports Streamable HTTP, HTTP POST, SSE, stdio bridge, and Chrome Native Messaging MCP transports.
- Manual chat and automation tasks share dynamic tool schemas, execute MCP calls automatically, and continue with `<tool_results>` in the same DeepSeek conversation.
- Adds side-panel automation tasks, independent sessions, run-now, cron/RRULE scheduling, run history, PoW/auth compatibility, and failure status display.
- Refactors the tool-call core into a provider-neutral runtime; built-in memory tools and MCP tools share the same descriptor, parsing, filtering, and history-restore pipeline.
- Adds update/delete tools to the memory system and improves relevant-memory filtering, thinking mode, and collapsed tool execution display.
- Adds the `/skill` autocomplete panel, system prompt presets, preset import, Expert mode switching, WebDAV sync, and custom DeepSeek page backgrounds.
- Adds README screenshots, MCP usage instructions, mock verification scripts, TypeScript fixes, and the official release workflow.
