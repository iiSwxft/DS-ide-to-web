## DeepSeek++ 1.11.5

1.11.5 is a chat, MCP, and Shell Host stability update, mainly reducing interruptions caused by request format changes, repeated refreshes, and long-running local tool calls.

### Key Changes

- **Basic chat is not interrupted**: when a certain type of DeepSeek request cannot be safely enhanced by the extension, it is sent on as the original request, so ordinary chat is not blocked or aborted by the extension.
- **MCP permission confirmation recovery**: when connecting an MCP service that needs website permissions from the side panel, the browser permission confirmation is started directly by the current user action, reducing cases where authorization fails after clicking connect.
- **More stable MCP tool lists**: tests and refreshes of the same service run in order; when a refresh fails, the most recent successfully discovered tools are kept while the connection error is shown clearly.
- **Shell Host stays responsive**: while running long local tools, initializing the Windows command environment, or opening the folder picker, tool lists and other control requests still respond promptly, and returned results are output steadily.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

### Verification

- `npm run ci:quality`
- `npm pack --dry-run --workspace packages/shell-host`
- `node scripts/web-search-smoke.mjs`

### Chrome Web Store Update Notes

- Sends the original request when it cannot be safely enhanced, reducing interruptions to everyday chat.
- Fixes site-permission prompts not appearing correctly for some MCP service connections.
- Keeps the last available MCP tool list after a failed refresh and makes repeated tests and refreshes more reliable.
- Keeps the Shell Host responsive during long native tool calls and Windows startup work; the Chrome package adds no new browser permissions.
