## DeepSeek++ 1.0.2

1.0.2 is a Shell MCP and tool result experience enhancement release, letting local commands keep context across a continuous session and making English/Chinese tool feedback, command results, and release verification steadier.

### Key Changes

- **Persistent Shell sessions**: Shell MCP adds persistent session tools that can open, reuse, and end the same local shell session, suited for continuous tasks that need to keep the current directory, environment variables, or interactive state.
- **Command result feedback**: when a shell command ends the session itself, the output, exit code, and status of that command are still returned, reducing information loss after long or one-off commands end.
- **Tool result language**: Skill draft, memory import, and artifact-related tool result cards continue to fill in English/Chinese copy, so readability is more consistent after switching the side-panel language.
- **Release script reliability**: release, automation, i18n, manifest, and asset verification scripts are steadier when run from different directories, lowering the risk of finding the wrong project root in cross-platform execution.
- **Regression coverage**: strengthens tests related to Shell persistent sessions, command exit results, tool result rendering, shell policy, and release script paths.
