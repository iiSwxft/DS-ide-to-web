## DeepSeek++ 0.7.5

0.7.5 is a local Skill workflow and Agent output stability release, making it easier to bring local Skills into DeepSeek++ while keeping history replies, automation, and inline agent wrap-ups cleaner.

### Key Changes

- **Local Skill management**: the Skill page adds local Skill preview, import, and sync, letting personal or team local Skill folders join the DeepSeek++ workflow.
- **Reviewable before import**: before a local Skill is imported, its name, description, source, and availability status are shown so users can confirm the content before enabling it.
- **Cleaner history replies**: when restoring old conversations, `task_complete` tool blocks are shown as a more natural summary, reducing technical marker noise.
- **Steadier automation runs**: the PoW header is now created on demand, lowering the chance that automation tasks are interrupted during request preparation.
- **Less duplication in inline agent wrap-up**: when a task has already provided a completion summary, the inline agent reuses it instead of generating the final summary again.
- **Product assets updated**: README and Chrome Web Store assets use new product screenshots, showing the side panel, tool execution, automation, and project capabilities closer to the current UI.
- **Regression coverage strengthened**: adds tests for local Skill import, sync merge, Shell Host local preview, history cleanup, PoW, inline agent, and injected styles.
