## DeepSeek++ 1.12.1

1.12.1 is an experience fix and reliability hardening release: local large file reads are no longer truncated, Firefox gains a toolbar entry, side-panel tabs can scroll, the inline agent step timeline is clearer, and MCP transport and the sandbox are hardened.

### Key Changes

- **Local file reading (Shell host)**: `local_file_read` now uses deterministic automatic continued reading: when reading a large file beyond the single-read limit, it continues automatically to the end, and mixed emoji and Chinese content is no longer truncated; very large files are read on demand by character windows and no longer loaded into memory whole. Thanks to [@zhangweildlh](https://github.com/zhangweildlh) for the implementation and the multiple review rounds.
- **Firefox toolbar entry**: the Firefox toolbar adds a DeepSeek++ button that opens the side panel, matching how Chrome/Edge work.
- **Side-panel tab scrolling**: when the tab strips in Settings, Capabilities, and Library overflow, left and right arrows appear so hidden tabs can be scrolled to in one click; tabs switched by keyboard scroll into view automatically.
- **Inline agent timeline**: Agent steps are displayed more clearly: process text is separated from the final answer, tool calls show success/failure status per row and can expand their summaries independently; completed steps collapse only the process text, keeping tool rows easy to scan.
- **Simplified tool execution mode**: removes the manual confirmation mode; enabled tools execute automatically, and "Disabled" becomes the only way to opt out.
- **Reliability and security hardening**: MCP connections and reads gain timeout protection and endpoint validation; tool parsing is changed to linear time (removing the risk of stalls on extreme input); sandbox HTML content pins resource origins and limits result size; web reads allow only http(s) addresses.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
