## DeepSeek++ 1.11.3

1.11.3 is an MCP and chat stability update, keeping the tool lists of connected services and the local Skill workflow available after refresh.

### Key Changes

- **MCP tool list recovery**: fixes the issue where the tool count still showed 0 after a successful service test; discovered tool lists are no longer wrongly cleared by status updates.
- **Local Skill import recovery**: the local folder picker tool of Shell MCP continues to appear in the local Skill import flow, making it easy to select and import local Skill folders.
- **Chat and tool stability**: reduces chat or tool state anomalies caused by page runtime messages interfering with each other, making ordinary chat and authorized tool connections steadier.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

### Verification

- `npm run ci:quality`
- `npm pack --dry-run --workspace packages/shell-host`
- `node scripts/web-search-smoke.mjs`

### Chrome Web Store Update Notes

- Fixes cases where an MCP service test succeeds but its tool list still shows 0.
- Improves folder selection and Shell tool recovery when importing local Skills.
- Makes normal chat and authorized tool connections more stable after page refreshes.
- The Chrome package adds no new browser permissions.
