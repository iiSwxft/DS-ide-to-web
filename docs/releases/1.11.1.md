## DeepSeek++ 1.11.1

1.11.1 is an update focused on the reliability and controllability of MCP tool connections: it is compatible with more service versions still in use, fixes tool failures affecting subsequent conversation, and offers a clearer management approach for large tool sets.

### Key Changes

- **MCP connection compatibility**: compatible with more MCP service versions still in use, reducing cases where the connection succeeds but tools are unavailable.
- **Tool call recovery**: after problems in MCP tool discovery or calls, you can recover through refresh and subsequent conversation; after tool results return, the same round of the task can continue.
- **Large tool set management**: a single MCP service can be set to show tools directly, adapt on demand, or call on demand, better suited to services with many tools while keeping the user in control of the actual tools.
- **Consistent execution experience**: manual chat, Agent, the side panel, and automation tasks use consistent tool availability and authorization rules.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
