## DeepSeek++ 1.12.2

1.12.2 is a tool execution transparency and production experience fix release: failures of tools such as shell_exec are no longer a black box, diagnostic logs can be exported in one click, long outputs are saved automatically, full output can be copied, the export content scope is selectable, and the inline agent's continuation count matches the actual step count.

### Key Changes

- **Tool execution transparency**: when tools such as `shell_exec` fail, the actual command executed and the failure reason are shown; when authorization is denied, the specific reason is shown (such as authorization off, expired, session mismatch, tool disabled). Settings → Data adds an "Export diagnostic log" button that exports the tool execution, authorization, and error records within the most recent session in one click, making troubleshooting easier.
- **More accurate inline agent continuation count**: when paused at the automatic continuation limit, the prompt text now reports the number of steps actually completed, consistent with the "send 'continue' to continue" prompt.
- **Automatic saving of long outputs**: when an Agent produces long text, it is saved as an artifact automatically with a download entry shown, so you no longer need to ask it to call the download tool manually.
- **Copy full output**: the reply action area adds a "Copy full output" button that copies DeepSeek's complete reply at once, no longer limited by the official copy button.
- **Conversation export scope selection**: when exporting Markdown/HTML you can choose "Input + output only" or "Everything" (including tool calls, continuation info, thinking process, and extension-injected info), and the last choice is remembered, serving both troubleshooting and everyday archiving.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

Thanks to [@zhangweildlh](https://github.com/zhangweildlh) for detailed usage feedback on v1.12.0 ([#494](https://github.com/zhu1090093659/deepseek-pp/issues/494)); this release addresses the tool execution, export, copy, and long-content issues from it one by one.
