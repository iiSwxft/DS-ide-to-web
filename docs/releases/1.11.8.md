## DeepSeek++ 1.11.8

1.11.8 is an optional cloud sync reliability update, reducing cases where individual data files fail to upload or download while the sync service is temporarily busy.

### Key Changes

- **Steadier uploads**: sync uploads process data files in order, lowering the chance of a single file failing when the service temporarily limits concurrent requests.
- **Steadier downloads**: sync downloads likewise read files in order, reducing cases where individual saved items or other sync data cannot be downloaded while the service is busy.
- **Integrity unchanged**: local memory, Skills, presets, projects, and saved items are updated only after a complete set of sync data passes length and checksum verification.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
