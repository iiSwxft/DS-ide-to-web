## DeepSeek++ 0.5.0

0.5.0 is an automation and tool-continuation stability release, improving long-task handoff, history display cleanliness, and side-panel loading experience.

### Key Changes

- Automation tasks now save more reliable conversation links, parent messages, and history snapshots after completion, making later continued runs steadier.
- Automation tasks and manual Agent-style continuation use a consistent pace for tool execution and result return, reducing state differences in long tasks.
- Conversation history and the local cache now consistently hide internal prompts and raw tool-call markers while keeping restorable tool execution records.
- Output speed display is consistent between streaming replies and compatible request paths, reducing stale speed state.
- The side-panel Memory, Skill, Preset, Automation, MCP, and Settings pages are now loaded on demand, making first open lighter.
- Adds a prompt freeze check that confirms before release that key system prompts, tool formats, and continuation prompts have not been rewritten unintentionally.
- Archives outdated active planning docs as the current architecture baseline so later work stops referencing the old refactor plan.
