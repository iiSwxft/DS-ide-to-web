## DeepSeek++ 0.6.0

0.6.0 is a side-panel chat and Skill workflow enhancement release, moving DeepSeek++ from enhancing web chat to letting you start tasks directly in the side panel, manage custom Skills, and import Skills from GitHub.

### Key Changes

- After enabling it in Settings, the side panel adds a "Chat" page where you can send messages, start new conversations, and watch replies stream in.
- Selected web page text can be sent to side-panel chat from the right-click menu, or applied to a custom scenario template.
- Custom Skills can be edited, enabled, disabled, and deleted, making it easier to maintain a local skill library.
- Supports previewing and importing third-party Skills from a GitHub repository, directory, or a single `SKILL.md`.
- `web_fetch` supports per-site authorization when needed, and web sources can also be authorized in bulk on the Tools page.
- Fixes tool output being attributed to the wrong reply node, reducing misplaced results during continuation.

Thanks to this release's contributors: [@todayzhou](https://github.com/todayzhou) for side-panel chat and right-click scenarios, and [@IjalG](https://github.com/IjalG) for the `web_fetch` authorization experience.
