## DeepSeek++ 1.13.0

1.13.0 is an inline agent engine and local Skill management upgrade release: the inline agent moves to a more stable new runtime engine and supports an official API backend, Skills imported from local folders are upgraded to index import with re-association and auto-activation, and background performance and the conversation export path are more reliable.

### Key Changes

- **Inline agent engine upgrade**: the inline agent runtime engine is upgraded as a whole, with a steadier tool execution and authorization chain and consistent continuation and event handling. After configuring a DeepSeek official API Key, the inline agent automatically switches to running on the official API backend (with reasoning support); when not configured, it still uses the page session chain, consistent with side-panel chat behavior.
- **Local Skill management upgrade**: Skills imported from local folders now use index import: the database stores only an index card, and content is read from disk on demand; supports re-association after a directory is relocated and implicit auto-activation. After a Skill is activated, the shell working directory in the conversation is automatically confined to that Skill directory, preventing out-of-bounds operations.
- **Skill ecosystem import**: supports importing SKILL.md skill packs from the pi/agentskills.io ecosystem, reusing the existing local import flow without adding storage keys.
- **Background performance optimization**: the background script is structurally slimmed down and i18n resources are trimmed by partition; storage reads and writes use the browser-native IndexedDB, for faster startup and response and lower memory usage.
- **Conversation export fixes**: exporting now fails with a clear message when the current conversation history is empty; when copying output fails, the specific reason is shown instead of failing silently.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

Thanks to [@zhangweildlh](https://github.com/zhangweildlh) for contributing the local Skill management upgrade ([#457](https://github.com/zhu1090093659/deepseek-pp/pull/457)): local folder index import, directory relocation re-association, implicit auto-activation, and the Skill session cwd safety fence.
