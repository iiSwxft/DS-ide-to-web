## DeepSeek++ 1.14.0

1.14.0 is an inline agent delivery experience upgrade and streaming stability fix release: final answers, charts, and code artifacts are now rendered natively by DeepSeek, the reasoning process is shown step by step, and streaming and code block rendering are more stable.

### Key Changes

- **Inline agent delivery upgrade**: the final answer is now rendered natively by the DeepSeek page, with mermaid/xychart chart cards, runnable html/svg/xml code blocks, and the native preview panel shown directly; the extension-side artifact rendering flow is removed.
- **Reasoning process display**: the thinking process is captured and shown turn by turn, and automatically collapsed into a "Thinking · Step N" entry when complete; the final answer is fully expanded (the render limit is greatly raised) and is no longer collapsed or truncated.
- **Console positioning and recovery**: the new console mounts on the latest message, recovery positioning under the virtual list window is more reliable, and the complete final reply is restored to its expanded state correctly.
- **Streaming and rendering stability**: fixes streaming framing that could lose some reasoning/body increments; code block cross-frame collapsing no longer breaks blank lines inside fences; code run status is preserved after streaming re-renders; turns with only thinking content are no longer resubmitted (avoiding conversation chain forks).
- **Regenerate authorization fix**: authorization for native regenerate tool calls is fixed so that only successfully executed calls count as authorization evidence, and rejected or interrupted calls no longer widen the authorization scope.
- **Side panel**: the web streaming reasoning process is forwarded to the side-panel conversation for display.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
