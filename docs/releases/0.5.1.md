## DeepSeek++ 0.5.1

0.5.1 is the built-in web tools release, letting DeepSeek search, fetch, and continue generating directly when real-time information or web page content is needed.

### Key Changes

- Adds the built-in `web_search` and `web_fetch` tools, supporting web search and page text fetching.
- Web tool results are returned to the same conversation to continue generating, suitable for real-time lookups, fact checking, and page summaries.
- The side panel adds a "Tools" page where you can toggle web tools, authorize web sources, and run search diagnostics.
- When search results are empty, other available search sources are tried, avoiding treating unparseable pages as success.
- Search rules are injected only when `web_search` is available, so the model is no longer prompted to call it after the tool is turned off.
- Fixes duplicated body rendering after tool continuation completes, keeping step records and showing the final answer only once.
