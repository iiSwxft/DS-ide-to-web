## DeepSeek++ 1.0.7

1.0.7 is a diagnostics and stability update for the Shell Native Host and MCP stdio bridge, making local tool problems easier to troubleshoot and preventing oversized local payloads from breaking the bridge.

### Key Changes

- **Shell Native Host logging**: the installer adds a `--log-file <path>` option that writes the local host runtime log to a specified file, making it easier to troubleshoot local tool issues such as `local_file_write`; the status page recognizes the log path, and paths containing spaces or special characters are parsed correctly.
- **Local host startup logging**: the local host automatically creates the log directory and writes a startup line when it starts; a log write failure is reported once on stderr instead of being silently swallowed.
- **Local payload size protection**: the Shell Host channel adds local payload size validation, rejecting oversized `local_file_write` content or whole envelopes before opening the local port, preventing oversized writes from breaking the bridge; multimodal image/video analysis is not affected by this limit.
- **stdio bridge UI**: the URL field for stdio_bridge in the MCP server form is renamed "Bridge endpoint URL" with a hint, guiding users of local executables to use the Shell Native Host preset instead and reducing connection failures from mistakenly entering a local exe path.
- **Regression coverage**: adds tests for installer log path round-trips, local payload size validation, the envelope-over-limit branch, notification paths, multimodal regression, log directory creation, and stderr diagnostics.

### Chrome Web Store Update Notes

- The Shell Native Host installer adds a `--log-file` option so native tool runs can be logged to a file for easier troubleshooting.
- The native host now creates the log directory and writes a startup line automatically; log write failures are reported once to stderr instead of being silently ignored.
- The Shell Host channel checks native payload size before opening the native port and rejects oversized native write content or envelopes early, preventing oversized payloads from breaking the bridge; multimodal image/video analysis is not affected by this limit.
- The stdio bridge URL field in the MCP service form is relabeled as "Bridge endpoint URL" with a hint pointing local-executable users to the Shell Native Host preset, reducing connection failures caused by entering a local executable path.
