## DeepSeek++ 0.6.4

0.6.4 is a side-panel chat and local tools enhancement release, making the DeepSeek++ chat entry on ordinary web pages more independent and letting Shell MCP support Python interpreter workflows.

### Key Changes

- After configuring an official API Key, side-panel chat and right-click scenarios can be used on ordinary web pages without relying on the DeepSeek page login state.
- Selected text can be sent directly to side-panel chat or applied to a custom scenario, suited for summarizing, explaining, and rewriting across web pages.
- Shell MCP adds the `python_exec` capability, with clearer enablement, permission, and status management on the side-panel Tools page.
- The Shell Host tool protocol, execution policy, and smoke test coverage are strengthened together, reducing state differences between local commands and interpreter tools.
- Development dependency vulnerabilities are fixed, and pre-release checks continue to cover multi-browser packaging, MCP, automation, prompt freeze, workflow, and asset verification.

Thanks to this release's contributor: [@IjalG](https://github.com/IjalG) for the Python interpreter / `python_exec` capability.
