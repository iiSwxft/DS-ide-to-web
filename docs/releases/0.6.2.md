## DeepSeek++ 0.6.2

0.6.2 is a conversation export and cross-platform Shell experience enhancement release, letting users archive DeepSeek conversations locally and improving the stability of the Windows local command path.

### Key Changes

- The side panel adds an "Export" page that can export DeepSeek conversations accessible to the current account as JSON, Markdown, or printable HTML.
- Exports support a readable mode and a raw mode, and record attachment references, file names, sizes, status, and message associations.
- Path resolution and Chinese output for the Windows Shell Host are more reliable, reducing garbled text and command-not-found issues when running local commands.
- Adds Vitest unit tests covering request enhancement, MCP transport, memory tools, sync schema, Shell policy, and the export flow.
- The release workflow now verifies version consistency before publishing and confirms the Shell Host npm package is visible before uploading browser extension assets.
