## DeepSeek++ 1.0.9

1.0.9 extends the side-panel chat entry to ordinary web pages and fixes login and session recovery issues when automation tasks run in the background, making cross-page use and scheduled tasks steadier.

### Key Changes

- **Global floating chat entry**: non-DeepSeek web pages show a draggable DS++ Chat floating entry; click it to open a lightweight chat window, suited for asking DeepSeek++ directly while browsing.
- **Controllable and privacy boundaries**: floating chat can be turned off in the Appearance section of Settings; the entry itself does not automatically read or send page body content, and content enters the chat flow only when the user actively types, sends, or uses the selected-text scenario.
- **Automation login stability**: when automation tasks run in the background they use available DeepSeek login information, so logged-in users are no longer wrongly told to log in again because the background environment cannot get the page token.
- **Automation session recovery**: conversation links and history snapshots in automation results point to the correct DeepSeek conversation when run in the background, making task results easy to open and track.
- **Regression coverage**: release verification continues to cover compile, tests, automation contracts, MCP/Shell/PoW smoke, multi-browser builds, and release asset checks.

### Chrome Web Store Update Notes

- Adds a DS++ Chat floating launcher on normal web pages, opening a lightweight chat window on click; the launcher is draggable and can be turned off from Appearance settings.
- The floating launcher does not automatically read or send page body content; content enters chat only when the user types, sends, or uses a selected-text scenario.
- Fixes background automation falsely reporting a missing DeepSeek login token, so signed-in users can run scheduled or manual automation more reliably.
- Fixes automation result session links and history snapshots resolving incorrectly from the background environment.
