## DeepSeek++ 1.0.3

1.0.3 is a cloud sync, prompt reuse, and MCP connection enhancement release, letting saved items enter conversations faster, extending sync sources to Google Drive / OneDrive, and improving the reliability of local Shell and Streamable HTTP MCP.

### Key Changes

- **Saved item insertion**: frequently used prompts, snippets, and bookmarks on the Saved page and in the library can be inserted directly into the current chat input box, making it easier to reuse fixed instructions and workflows.
- **Cloud sync sources**: sync settings add Google Drive and OneDrive while keeping WebDAV; Drive / OneDrive use the user's own OAuth app configuration, and data is written to the corresponding cloud app space only after the user enables sync.
- **MCP connection**: MCP HTTP transport supports Streamable HTTP sessions, making discovery, connection, and execution status of remote tool services steadier.
- **Shell security boundary**: the Shell MCP execution environment now uses a minimal set of environment variables, reducing sensitive variables in the host process being inherited by local commands; Windows PowerShell persistent sessions are also steadier.
- **Sync compatibility**: after a GitHub Skill is imported from the repository root, cross-device sync downloads no longer fail validation because of an empty rootPath.
- **Regression coverage**: adds tests for saved item insertion, cloud sync backends, MCP transport policy, GitHub Skill sync validation, and Shell environment isolation.

Thanks to this release's contributor: [@maoxin1234](https://github.com/maoxin1234) for improving Shell MCP environment isolation and Windows session stability.
