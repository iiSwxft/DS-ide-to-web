## DeepSeek++ 0.3.0

0.3.0 moves DeepSeek++ from a Chrome-only extension to multi-browser releases for Chrome / Edge / Firefox, while completing the light/dark experience, version consistency, and multi-browser release assets.

### Key Changes

- Adds Chrome, Edge, and Firefox MV3 build and packaging scripts: `build:chrome`, `build:edge`, `build:firefox`, `build:all`, `zip:chrome`, `zip:edge`, `zip:firefox`, `zip:all`.
- The WXT manifest is now generated per target browser: Chrome/Edge keep `sidePanel`, while Firefox gets a compatible sidebar entry and a stable Gecko ID.
- The release workflow now runs `zip:all` and uploads all browser zips instead of publishing only a single Chrome package.
- Reworks the top side-panel navigation into a stable tab component, improving icons, text, and current-page state in narrow side panels.
- Adds DeepSeek page theme detection and sync; the side panel, Skill popup, tool execution cards, tool result blocks, and custom background overlay all adapt to light and dark themes.
- Colors and status styles in the Settings, Memory, and MCP pages now use theme tokens, reducing hard-coded light colors.
- The top version badge, the version at the bottom of Settings, and MCP clientInfo now read the version from the extension manifest, fixing the issue where 0.1.0 was still shown.
- MCP Native Messaging, installation instructions, and verification docs are reworded to be browser-neutral, with load entry points added for Chrome / Edge / Firefox.
- Archives the MCP rollout docs and adds an Edge/Firefox support archive, preserving verification records and manual test leads.

### Verification

- `npm run compile`
- `npm run build:all`
- `npm run zip:all`
- `npm run smoke:mcp`
- `npm run verify:mcp:mock`
