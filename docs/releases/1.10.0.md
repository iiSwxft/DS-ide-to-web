## DeepSeek++ 1.10.0

1.10.0 improves resource import and on-demand reading for local Skills, making file status, read conditions, and failure repair for large Skills clearer, and improving the parameter accuracy of MCP proxy tools.

### Key Changes

- **Clearer resource status**: local Skill preview distinguishes files embedded in the Skill from supporting files kept in the original directory and readable on demand, no longer causing the misunderstanding of lost files through "omitted".
- **Read capability check**: before import, it confirms whether Shell MCP can actually read on-demand resources; when unavailable, it gives clear hints to update the Native Host, adjust the execution mode, or check the connection.
- **Mixed directories can still be imported**: when a single Skill is blocked because the reader is unavailable, other Skills in the same directory that do not depend on that capability can still be selected and imported.
- **More accurate MCP parameters**: optional values of MCP tool input parameters are fully preserved through discovery, caching, and the prompt chain, improving call accuracy for proxied MCP tools.
- **Permission boundaries unchanged**: this update adds no browser permissions; on-demand resources remain in the local Skill directory chosen by the user.

Thanks to [@zhangweildlh](https://github.com/zhangweildlh) for reporting the local Skill resource description issue and providing reproduction materials.
