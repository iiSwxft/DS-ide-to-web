## DeepSeek++ 0.6.1

0.6.1 is an automation, Shell MCP, and side-panel cleanup release, improving scheduled task reliability, local command execution, and the discoverability of side-panel capability entries.

### Key Changes

- Automation tasks are now wired into browser background scheduling, suited for ongoing topic tracking, fixed reminders, and periodic checks.
- Command execution on Windows and OfficeCLI / Shell skill prompts are more consistent, reducing path and command differences across platforms.
- Side-panel capability entries are consolidated into a unified page, making it more direct to find MCP, tool, Skill, and automation capabilities.
- The README adds an English entry point so English users can quickly learn the installation method and core capabilities.
- Release package verification now covers Chrome, Edge, Firefox, and the source package, lowering the risk of missing packages or version mismatches.
