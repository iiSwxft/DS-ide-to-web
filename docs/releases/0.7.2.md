## DeepSeek++ 0.7.2

0.7.2 is a Browser Control and side-panel experience enhancement release, letting DeepSeek++ perform visible web actions in a user-selected tab while making permission boundaries, third-party Skill management, and action feedback clearer.

### Key Changes

- **Adds Browser Control**: in the side panel under "Capabilities > Browser", enable Browser Control, choose a target tab, and let the model perform web actions such as navigation, clicking, hovering, typing, key presses, waiting for page content, handling dialogs, and uploading files.
- **Clearer permission boundaries**: Chrome / Edge packages add the permissions required for Browser Control; the feature is off by default, and page text snapshots and browser action tools are provided only after the user enables it and selects a target tab.
- **Clearer side-panel feedback**: saved items, project material, and prompt controls strengthen status prompts for success, failure, and backend unavailable, reducing cases where it is unclear whether an action took effect.
- **Easier third-party Skill management**: third-party Skills are grouped by source and support independent enabling, disabling, update checks, and sync, better suited to maintaining a larger Skill library.
- **More accurate platform capability display**: the Capabilities page distinguishes feature boundaries across browser extensions, Android WebView, and unsupported platforms, avoiding showing unavailable capabilities as available.
- **Regression coverage continues to grow**: adds tests for Browser Control, side-panel interaction, runtime broadcast, platform capabilities, and Skill localization; pre-release checks continue to cover multi-browser builds and asset verification.

### Chrome Web Store Update Notes

- Adds Browser Control: choose a target tab from the side panel so DeepSeek++ can run visible web actions such as navigation, clicking, filling, waiting for page content, file attachment, and dialog handling.
- Browser Control stays off by default; text snapshots and browser action tools are added to new conversations only after the user enables the feature and selects a tab.
- Chrome / Edge packages add the permissions required for Browser Control, with updated privacy policy and submission notes.
- Saved items, project material, prompt controls, and third-party Skill management now show clearer status feedback.
