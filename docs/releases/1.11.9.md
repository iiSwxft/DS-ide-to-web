## DeepSeek++ 1.11.9

1.11.9 is a chat and MCP usage experience update, fixing context injection after editing messages, output speed statistics, IME Enter handling, and MCP tool selection, and making DeepSeek native smart search work better together with extension tools.

### Key Changes

- **Context recovery after editing messages**: after editing a DeepSeek message, the memory, presets, and tool prompts injected by the extension continue to take effect as for a new message and are no longer lost.
- **More accurate output speed statistics**: model output speed counts only visible output and no longer includes hidden thinking text, avoiding inflated numbers.
- **IME Enter no longer submits by mistake**: when composing with an input method such as Chinese, pressing Enter to select a candidate word no longer sends the message early.
- **MCP compatibility and tool selection**: improves compatibility with MCP services that use standard streaming formats; in manual mode the tool selection state stays clear and selectable, distinguishing auto, selected, and disabled, and switching tools does not clear discovered service information.
- **Native search and tool coordination**: when using DeepSeek native smart search, ordinary conversation and Agent continuation keep using native search and no longer trigger the extension's own web search again; other tools are unaffected.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

- Fixes edited DeepSeek messages losing the extension's prompt and context, and premature message submission while confirming IME composition candidates.
- Model output speed statistics no longer count hidden reasoning text and now reflect visible output more accurately.
- Improves MCP streaming compatibility and manual tool selection, so switching tools no longer clears discovered service information.
