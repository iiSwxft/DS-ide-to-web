## DeepSeek++ 1.11.6

1.11.6 is a file generation stability update, mainly preventing abnormally large content from dragging down the page, or reappearing after refresh, when Skills such as OfficeCLI generate local documents.

### Key Changes

- **File generation no longer drags down the page**: adds a hard guard for abnormally large tool output, stopping processing once it exceeds the safe range, preventing long encoded file data strings from freezing the page.
- **No more reloading leftover content after refresh**: history restore cleans up incomplete, cross-segment, or whitespace-formatted tool output, avoiding large leftover content being rendered again after refresh.
- **Clear Artifact usage boundaries**: Artifacts are for UTF-8 text, code, and project bundles made of text; local binary files such as Office, PDF, images, and archives should stay at the generated path and be reported to the user directly, not encoded into the chat.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

### Chrome Web Store Update Notes

- Fixes page freezes caused by unusually large output when OfficeCLI and similar Skills create local files.
- Cleans up unfinished or split tool output during history restoration so stale large content does not return after a reload.
- Clarifies that Artifacts are for text and code, while local Office, PDF, image, and archive files remain at their generated path. The Chrome package adds no new browser permissions.
