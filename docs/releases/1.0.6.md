## DeepSeek++ 1.0.6

1.0.6 is a Skill and local tool stability update, bundling the spec-driven-develop workflow, improving the GitHub/local Skill import experience, and making artifacts, Shell tool results, and DeepSeek reasoning page detection more reliable.

### Key Changes

- **Built-in Skill library**: adds the spec-driven-develop, deep-discuss, and review-spd workflows, letting you enable structured requirements analysis, deep discussion, and code review templates from the Skill page.
- **Skill import stability**: GitHub Skill import makes fewer requests, and local Skill import supports nested directories and preview, lowering the failure rate when importing large Skill libraries.
- **Artifacts and tool results**: generated artifacts are persisted and can still be restored after a refresh; large tool results use externalized payloads, reducing oversized messages or interrupted continuation in long tasks.
- **Shell Native Host**: the Shell tool handles local Skill preview, stdio bridging, and permission policy more steadily, making command-style local workflows easier to integrate.
- **DeepSeek page compatibility**: DeepSeek reasoning pages are recognized more accurately, so tool block styles and enhancements stay available on more DeepSeek page forms.
- **Regression coverage**: adds regression tests for Skill import, the Shell host, local Skill preview, artifact restoration, externalized tool payloads, streaming tool parsing, and bridge transport.
