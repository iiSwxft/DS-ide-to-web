## DeepSeek++ 1.11.4

1.11.4 is a tool workflow and Windows Firefox local connection stability update, mainly fixing problems where tool authorization, tool result continuation, and multi-browser Shell MCP installation affected each other.

### Key Changes

- **Tool authorization recovery**: fixes cases where confirmed tools could still be wrongly rejected after creating, switching, or refreshing a DeepSeek conversation; "Authorize all websites" in the side panel can again start the website permission confirmation normally.
- **Tool continuation recovery**: tool completion and conversation end events are handled in the correct order, reducing cases where the conversation does not continue generating after a tool such as web search runs once.
- **MCP tool list stability**: service health checks and status updates no longer wrongly clear discovered tool lists.
- **Windows Firefox Shell MCP**: each Windows browser uses its own local Host manifest, so Firefox no longer overwrites Chrome, Edge, or Chromium when installed alongside them.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

After upgrading the extension, Windows Firefox users need to reinstall the Shell Host once and restart Firefox:

```bash
npx deepseek-pp-shell-host@1.11.4 install --browser firefox
```

### Verification

### Chrome Web Store Update Notes

- Fixes confirmed tools being rejected after switching or reloading a DeepSeek conversation.
- Fixes cases where a conversation did not continue after a tool completed, while keeping MCP tool lists stable.
- Fixes the Windows native-host conflict when Firefox Shell MCP is installed alongside another browser.
- The Chrome package adds no new browser permissions.
