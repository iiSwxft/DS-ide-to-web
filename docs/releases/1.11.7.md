## DeepSeek++ 1.11.7

1.11.7 is a long conversation recovery and MCP connection reliability update, mainly reducing cases where historical tool records disappear after refresh, page switches, or message remounts, and where saved MCP service status goes out of sync.

### Key Changes

- **More reliable long conversation recovery**: historical tool cards, Artifact results, and Agent continuation records are restored when their corresponding messages appear after a refresh, route change, or segmented loading.
- **Cleaner conversation display**: history keeps the slash commands the user actually typed and no longer shows the internal expansion text of Skills in the conversation.
- **More consistent MCP service status**: service discovery results and health status are saved together; when connection configuration changes during a refresh, old results no longer overwrite the latest configuration.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.
