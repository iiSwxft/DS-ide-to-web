## DeepSeek++ 1.11.2

1.11.2 is a stability update, making basic chat and existing MCP connections easier to restore to a normal working state after an upgrade.

### Key Changes

- **New conversation recovery**: fixes the issue where the first message could be interrupted when creating a new DeepSeek conversation, so ordinary chat can start normally and receive replies.
- **Existing MCP connection recovery**: after an upgrade, still-valid MCP service configurations are recognized and restored, reducing the need to rebuild connections manually because of old caches.
- **Conversation continuity**: when the page creates or switches conversations, authorized tools keep working against the browser conversation the user is viewing, without affecting normal chat.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

### Verification

- `npm run ci:quality`
- `npm pack --dry-run --workspace packages/shell-host`
- `node scripts/web-search-smoke.mjs`

### Chrome Web Store Update Notes

- Fixes cases where the first message in a new DeepSeek conversation could stop before a reply.
- Improves recovery of existing MCP service configurations after an upgrade.
- Makes normal chat and authorized tool use more stable across conversation transitions.
- The Chrome package adds no new browser permissions.
