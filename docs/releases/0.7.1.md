## DeepSeek++ 0.7.1

0.7.1 is a tool-call and context-injection stability release, helping long replies, downloadable artifacts, memory, and Skills work together more steadily within the same task chain.

### Key Changes

- **More stable tool execution**: tool calls in long replies are recognized and executed earlier and more reliably, reducing tool blocks lingering in the body, duplicate triggers, or waiting until the full reply ends before processing.
- **Smoother downloadable artifacts**: single-file and project-bundle artifact generation is better suited to streaming execution, so the page stays more interactive while long content is generated.
- **More reliable memory and Skill context**: memory, Skills, and system prompts enter the task context more accurately across multi-step continuation and history organization, reducing lost or duplicated context injection.
- **Cleaner reply body**: tool-call content is separated from ordinary Markdown output more clearly, so users see a cleaner reply body and tool execution results.
- **Regression coverage continues to grow**: adds and strengthens automated coverage for tool parsing, streaming text, history cleanup, page execution, and product surfaces, lowering regression risk in long tasks.
- **Release quality continues to consolidate**: build tool dependencies move back to dev dependencies and the production dependency audit is back to 0 vulnerabilities; release asset verification continues to cover Chrome, Edge, Firefox, and the source package.
