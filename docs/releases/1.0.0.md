## DeepSeek++ 1.0.0

1.0.0 is the mature release of multimodal media and the side-panel workbench, letting DeepSeek++ bring images, video, MCP, local tools, and a clearer management UI into one browser task flow.

### Key Changes

- **Multimodal media enters the conversation flow**: after installing the Multimodal Native Host, you can add images or videos in the DeepSeek input box; the media is first analyzed through your configured OpenAI / Gemini, and the analysis result is brought back into the current message to continue generating.
- **Multimodal configuration consolidated**: the side panel adds multimodal API settings where you can configure OpenAI / Gemini keys, models, and request URLs, and create, test, and enable the `Multimodal` preset from the MCP page.
- **More stable media tasks**: multimodal requests extend their wait time according to the number of images and videos, reducing cases where larger media or multi-file analysis is interrupted too early before returning.
- **Clearer Artifact display**: generated artifact results are shown outside the collapsed tool block, making the body text and downloadable artifacts easier to tell apart and view.
- **More mature side-panel management**: Settings is split into General, API, Appearance, Data, Prompts, Voice, and About sub-pages, and the MCP, Tools, Skill, and Automation pages gain better loading states and confirmation feedback.
- **Interface consistency continues to be polished**: tool cards, the Skill popup, injected styles, and side-panel controls share a unified visual density, status feedback, and accessibility.
- **Store and privacy materials synced**: Chrome Web Store copy and the privacy policy add the data boundaries for multimodal API Keys, user-selected media, and the local Native Host.
