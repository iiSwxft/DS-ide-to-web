## DeepSeek++ 0.4.1

0.4.1 is an experience-enhancement release built on 0.4.0, introducing the floating DeepSeek page pet while keeping the README / release notes / version number consistent with the official release assets.

### Key Changes

- Adds the "DeepSeek Little Whale" floating pet, which shows state feedback on DeepSeek pages for thinking, outputting, tool execution, success, failure, and sleeping.
- Settings adds a pet toggle, fixed bottom-left/bottom-right positions, drag-to-position, size, opacity, and animated floating controls.
- The pet toggle, position, and appearance settings are stored locally in the browser and persist after page refresh.
- Pet image assets are now included in the extension's accessible resources so the floating pet renders correctly on DeepSeek pages.
- The README adds a floating pet feature introduction and a 0.4.1 change recap, and continues to keep 0.4.0 / 0.3.0 / 0.2.0 as collapsed history.
