## DeepSeek++ 0.4.4

0.4.4 is a Shell MCP store-install experience fix, letting users who install from the browser store also complete local Shell Host setup following the side-panel instructions.

### Key Changes

- Adds a publishable `deepseek-pp-shell-host` npm installer; users can install the Shell Native Host with `npx deepseek-pp-shell-host install ...`.
- The Shell Host is now installed into the user directory and no longer depends on the extension source directory.
- The installer supports Chrome, Edge, Chromium, and Firefox, and provides `install`, `status`, and `uninstall` commands.
- The Shell hint in the MCP side panel is now a store-user-oriented `npx` command with the current extension ID filled in automatically.
- Provides a clear message when the Native Host is installed but the extension ID is not authorized, avoiding misreading `forbidden` as not installed.
- The README, Chrome Web Store copy, and MCP instructions are aligned to the user install path, while source install commands are kept only as a developer entry point.
