## DeepSeek++ 1.0.4

1.0.4 is a side-panel chat and Skill management experience update, letting web chat switch between Default, Expert, and Vision modes, letting Vision mode attach images on request, and making memory/Skill injection, Agent stop feedback, and bulk Skill toggles steadier.

### Key Changes

- **Web model modes**: Settings and side-panel chat can choose Default, Expert, or Vision mode; side-panel API chat continues to use the model settings on the chat page.
- **Vision image attachments**: in Vision mode, web-login side-panel chat can select or paste images and shows upload status before sending; images enter the DeepSeek conversation only when the user actively sends that message.
- **Memory and Skill injection**: combinations of side-panel input, memory, Skills, project context, and saved item insertion are steadier, reducing context overwriting each other or unclear ordering.
- **Agent stop feedback**: when automatic tool continuation reaches the turn limit, a pause notice is shown explicitly, avoiding treating intermediate text that still awaits continuation as the final answer.
- **Bulk Skill toggle**: third-party or imported Skill groups support enabling/disabling in one action, reducing state inconsistency from multiple saves.
- **Regression coverage**: adds tests for web model modes, Vision image attachments, side-panel prompt composition, inline agent stop boundaries, and bulk Skill toggles.

### Chrome Web Store Update Notes

- Side-panel web chat now supports Default, Expert, and Vision mode switching. Vision mode can attach explicitly selected or pasted images.
- User-selected images enter the DeepSeek conversation only when the user sends that message, with upload state shown before sending.
- Memory, Skills, project context, and saved-item insertion compose more reliably with fewer context ordering or overwrite issues.
- Automated tool continuation now shows a clear pause notice at its boundary, and third-party or imported Skill groups support batched enable/disable actions.
