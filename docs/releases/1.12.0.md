## DeepSeek++ 1.12.0

1.12.0 is an Agent workbench and file reference experience update, making inline agent runs more reliable with clearly visible steps, and supporting @ references to files in trusted directories within chat.

### Key Changes

- **Structured Agent step UI**: Agent runs show clear steps and a global run indicator, the loop no longer ends silently, repeated steps have a retry cap to avoid infinite loops; results of window-type tools (such as Browser Control) are shown per window, and continuation prompts are more accurate.
- **Native search coordination**: when an Agent uses DeepSeek native smart search, the extension's own web search tool is no longer triggered, avoiding duplicate searches.
- **Trusted directories and @ file references**: adds a "Project files" settings page where you can choose local trusted directories with a scan budget; in chat, use @ to open the reference panel and send images from the directory into the conversation. It only takes effect inside directories you selected and saved, and content outside the path is ignored.
- **File reference robustness**: image MIME normalization avoids uploading the same image repeatedly; when the extension context is invalidated (such as stale pages left after reloading the extension), memory save failures are no longer falsely reported.
- **Usage chart fix**: the X axis of the 30-day token trend chart shows only dates, and labels no longer spill out of the chart panel.
- **MCP compatibility**: the MCP client capability declaration is changed to valid values that conform to the protocol spec, making connections steadier with servers that validate client capabilities.
- **Page loading cleanup**: extension pages no longer output modulepreload links, removing related noise in the browser console.
- **Permission changes**: no new browser permissions for Chrome, Edge, or Firefox.

### Chrome Web Store Update Notes

- Agent runs are more reliable: structured step UI with a global running indicator, visible loop endings, bounded step retries, and no duplicate built-in web search when DeepSeek native intelligent search is active.
- New trusted directory and @ file references: after choosing a local directory in Settings, you can reference images from it in chat with @; only your chosen directory is scanned and out-of-bounds paths are ignored.
- Fixes the 30-day token trend X-axis overflow and false save-failure reports after an extension context becomes invalid; improves compatibility with some MCP services.
- The Chrome package adds no new browser permissions.
