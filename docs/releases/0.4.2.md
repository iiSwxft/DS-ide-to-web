## DeepSeek++ 0.4.2

0.4.2 is a release-preparation and privacy-display release, completing the Chrome Web Store submission materials and preventing internal prompts and tool format reminders from being exposed on DeepSeek pages or in history.

### Key Changes

- Adds Chrome Web Store listing materials, including store copy, privacy policy, submission process, permission explanations, review notes, and required screenshot assets.
- Adds a Chrome Web Store upload workflow and a local submission script, supporting dry-run, upload-only, and upload-then-submit-for-review paths.
- Pages and history now strip internal prompt markers and tool format reminders, keeping only user-visible prompts and readable tool execution results.
- Streaming reply parsing more strictly distinguishes real reply text, thinking content, and non-reply events, reducing cases where internal context takes part in tool-call parsing.
- Adds the Chrome Web Store credentials environment file to the ignore list so local submission secrets are not committed by mistake.
- The README adds a 0.4.2 change recap, and continues to keep 0.4.1 / 0.4.0 / 0.3.0 / 0.2.0 as collapsed history.
