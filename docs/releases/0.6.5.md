## DeepSeek++ 0.6.5

0.6.5 is a bilingual runtime experience and output feedback calibration release, making DeepSeek++ more consistent in Chinese or English workflows and making the live output speed display closer to actual generation.

### Key Changes

- Language selection continues to cover the side panel, context menus, tool results, built-in Skills, and model continuation prompts, for a more consistent Chinese or English experience.
- User-created memories, presets, custom Skills, automation tasks, and sync data keep their original text and are not translated or rewritten when the interface language is switched.
- The `tok/s` estimate is calibrated to better match DeepSeek output characteristics and starts timing after the first streamed content, reducing deviation from queuing and prefill latency.
- The README and store materials reflect Chrome Web Store availability and continue to keep the Shell MCP and local tool installation notes.
- Release gates add multilingual coverage checks, continuing to cover compile, unit tests, MCP, automation, prompt freeze, multi-browser packaging, workflow, and asset verification.

Thanks to this release's contributor: [@mekos2772](https://github.com/mekos2772) for fixing the token output speed estimation deviation.
