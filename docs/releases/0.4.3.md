## DeepSeek++ 0.4.3

0.4.3 is a long-task stability and interactive feedback release, mainly improving DeepSeek verification compatibility, the pacing of Agent-style continuous execution, and the floating pet's state feedback.

### Key Changes

- Updates how local DeepSeek verification is computed, reducing interruptions in long tasks, automation, and tool continuation caused by platform verification failures.
- Agent-style continuous execution now automatically leaves an interval between consecutive requests, lowering the chance that multi-step tool continuation runs too fast and fails.
- Empty continuations now fail explicitly and keep existing step state, preventing long tasks from appearing finished without producing actual output.
- The DeepSeek Little Whale adds status speech bubbles that show and rotate feedback during thinking, outputting, tool execution, and idle states.
- Adds a standard issue form and template check; issues missing required information are closed automatically with a prompt to complete them.
- The README adds a 0.4.3 change recap, and continues to keep 0.4.2 / 0.4.1 / 0.4.0 / 0.3.0 / 0.2.0 as collapsed history.
