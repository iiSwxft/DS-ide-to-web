## DeepSeek++ 1.11.0

1.11.0 completes a round of stability and compatibility refactoring for PC browsers, mainly improving data safety, sync recovery, automation reliability, chat and tool runtime stability, and everyday loading performance during long-term use.

### Key Changes

- **Focused on PC browsers**: Chrome, Edge, and Firefox are currently officially supported; the Android template, build scripts, and mobile support entry points have been removed, and Android packages are no longer provided.
- **Local data and upgrade compatibility**: memory, Skills, presets, projects, saved items, MCP, automation, usage, and tool history use clearer versioning and validation rules; existing storage identifiers continue to be used, and corrupted data or unknown future versions raise explicit errors rather than silently overwriting the original content.
- **Sync and automation recovery**: sync uploads are published as complete generations, downloads are staged first and support rollback on failure; unfinished operations can be recovered after restart. Automation tasks strengthen cancellation, execution leases, and duplicate-trigger protection, lowering the chance of leftover or duplicated background tasks.
- **Steadier chat, tools, and local integration**: tightens input boundaries for runtime messages, DeepSeek requests, streaming tool calls, MCP transport, and the Native Host; floating chat, tool status, and error feedback are more predictable after an extension update or page reload.
- **Less everyday performance overhead**: merges frequent storage writes, centrally manages page listeners and lifecycle, and loads side-panel pages, built-in Skill resources, and the Python runtime on demand; the first Chat page build size drops by about 23% and the Chat route by about 84%, and key chunk and offline resource release budget checks are added.
- **Browser permission notes**: the permission sets for Chrome and Edge are unchanged; Firefox adds `identity`, used only for OAuth sign-in when the user actively enables Google Drive or OneDrive sync.

### Chrome Web Store Update Notes

- Strengthens validation and recovery for memories, Skills, presets, automation, and sync data while preserving existing local data.
- Improves reliability for scheduled tasks, chat, tool calls, MCP connections, and extension reloads.
- Reduces redundant storage writes and loads heavier pages and resources on demand.
- Official support now focuses on Chrome, Edge, and Firefox on PC; Android is no longer provided.
- The Chrome package adds no new browser permissions.
